Tips and suggestions

General

GetMeToSleep! defines a quiet period that will silence media and ring volumes when the device is charging. Main actions:
  • Set Time button to set the Start or End quiet times.
  • Enable service button to enable/disable the ChargingService Android foreground service. This manages the volumes when the phone is being charged or charging is disconnected.
  • Always restore volumes button if you always want volumes to be restored in charging disconnect, otherwise it will only restore volumes if it is withing the quiet times.
  • Debug mode to enable debug mode. This provides additional logging to diagnose problems.
Other actions (mainly for debugging):
  • Save Volumes saves the current volumes.
  • Show Saved Volumes shows the currently saved volumes.
  • Show Show Tasks shows the currently running tasks (e.g. ChargingService.
  • Kill Tasks kills the currently running tasks (e.g. ChargingService) in case they go rogue.
